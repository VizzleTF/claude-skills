# Fixes to writing-docs

The `technical-writing` and `technical-writing-ru` skills replace an earlier skill, `writing-docs`. A review of `writing-docs` found 16 defects. This page lists each defect, the section of each version that fixes it, and how.

Links lead to the English (EN) and Russian (RU) versions. `EN/` stands for `plugins/technical-writing/skills/technical-writing/`, `RU/` for `plugins/technical-writing-ru/skills/technical-writing-ru/`.

| # | Defect in writing-docs | EN | RU | How it is fixed |
|---|---|---|---|---|
| 1 | The sources table reads Write the Docs' ARID as "no duplicates". | [SKILL.md, Core rules](../plugins/technical-writing/skills/technical-writing/SKILL.md#core-rules) | [SKILL.md, Общие правила](../plugins/technical-writing-ru/skills/technical-writing-ru/SKILL.md#общие-правила) | The rule "Self-contained page" expands ARID correctly: Accept (some) Repetition In Documentation. |
| 2 | "Every page is self-contained" conflicts with "no fact is duplicated". | [SKILL.md, Core rules](../plugins/technical-writing/skills/technical-writing/SKILL.md#core-rules) | [SKILL.md, Общие правила](../plugins/technical-writing-ru/skills/technical-writing-ru/SKILL.md#общие-правила) | Context and prerequisites are restated on each page. Normative facts (a default, a limit, a flag) live in one place and are linked. README, tutorial and runbook allow repetition in their "Differences from the core rules" sections. |
| 3 | The NN/g figures from 1997 (79/16, +124%) open the skill as its main argument. | [sources.md, Sources the skill does not rely on](../plugins/technical-writing/skills/technical-writing/sources.md#sources-the-skill-does-not-rely-on) | [sources.md, На что скилл не опирается](../plugins/technical-writing-ru/skills/technical-writing-ru/sources.md#на-что-скилл-не-опирается) | The study is named with its setting, a promotional tourism site.
