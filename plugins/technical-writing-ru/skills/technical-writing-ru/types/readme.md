# README

README открывает репозиторий: его первым видит новичок. Он говорит, что это за проект, и доводит читателя до первого работающего результата.

## Когда это он и когда нет

README нужен как главная страница репозитория, пакета или каталога.

Выберите другой тип, если:

- нужно полное упражнение с проводником для новичка: tutorial со ссылкой из README;
- нужны все параметры инструмента: reference со ссылкой из README;
- нужны правила команды для участников: conventions со ссылкой из README.

## Каркас

1. Название и одно предложение: что это за проект и какую проблему он решает.
2. Для кого он, если это не видно из первого предложения.
3. Установка: команды и поддерживаемые версии.
4. Минимальный пример: самый короткий вызов, который даёт видимый результат, вместе с выводом.
5. Ссылки: документация, участие в разработке, лицензия, поддержка.

## Голос и глаголы

Описание пишется в изъявительном наклонении: «Разбирает YAML в типизированные структуры». Установка и пример пишутся в повелительном: «Установите через pip», «Запустите пример».

## Объём

Ориентир: один экран до ссылок, около 100 слов (эмпирика). Здесь работает совет Стива Круга для навигационных страниц: читатель пробегает страницу глазами, поэтому *happy talk* и инструкции, которые никто не читает, вырезайте. Всё, что идёт после первого результата, переезжает на страницы по ссылкам.

## Отличия от общих правил

- **Повтор допустим.** README повторяет шаги установки и предпосылки, которые есть и в документации: читатель должен получить первый результат, не уходя со страницы. Нормативные факты, например полный список параметров и их значения по умолчанию, остаются в reference, на них дана ссылка.

## Запрещено

- Приветственные абзацы и похвала проекту: `молниеносный`, `мощный`.
- Бейджи и логотипы, из-за которых первое предложение уезжает за край экрана.
- Changelog, полный список параметров или обсуждение архитектуры внутри README.
- Пример, который не работает в том виде, как написан.

## Чек-лист типа

- [ ] Первое предложение говорит, что это за проект.
- [ ] Команды установки работают как написаны и называют версии.
- [ ] Минимальный пример показывает свой вывод.
- [ ] Страница до ссылок помещается на один экран.
- [ ] Вместо оценок стоят факты.
- [ ] Ссылки ведут к остальной документации.
