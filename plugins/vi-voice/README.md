# vi-voice

Плагин задаёт стиль ответов Claude Code в чате: по-русски, вывод первой фразой, без церемоний, код и ошибки дословно. Тело ответа до 5 строк. В конце ответа идёт одна строка о том, что не проверено, и блоки с тем, что осталось сделать. Хук `SessionStart` при старте, `resume`, `clear` и `compact` добавляет в контекст файл [style.md](style.md): около 500 токенов на сессию. Сабагенты и документы плагин не трогает. Правила про код живут в плагине [vi-code](../vi-code/README.md).

## Установка

До версии 0.2.0 плагин назывался `voice-ru`. Если он стоит под старым именем, сначала удалите его: `/plugin uninstall voice-ru@vizzletf-skills`.

```
/plugin marketplace add VizzleTF/claude-skills
/plugin install vi-voice@vizzletf-skills
```

## Замер

Замер сделан на версии 0.1.1. 12 задач `claude -p`, по 2–3 прогона, без других хуков. Δ дана против прогона без стиля.

| Вариант | Длина ответа | Output без thinking | Стоимость | Точность 1–5 | Попадание в стиль 1–5 | Тесты кода |
|---|---|---|---|---|---|---|
| без стиля | 0% | 0% | 0% | 4,17 | 2,83 | 8/8 |
| vi-voice | −17% | −15% | в шуме | 4,17 | 4,08 | 5/6, с правилом о вызывающих 3/3 |

Точность и стиль оценивал Sonnet вслепую на 6 вопросах. Правило о вызывающих с версии 0.2.0 живёт в плагине code. Оно добавлено после того, как без него не исправлялся обходной код у вызывающего; с ним перепроверена только задача с багом.

Стоимость меняется в пределах шума (±10%): ответ модели занимает малую долю счёта. Плагин делает ответы короче и ближе к нужному стилю, а не дешевле.

## Удаление

```
/plugin uninstall vi-voice@vizzletf-skills
```
