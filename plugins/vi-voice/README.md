# vi-voice

Плагин задаёт стиль ответов Claude Code в чате: вывод первой фразой, без церемоний, код, ошибки, числа и отрицания дословно. Тело ответа до 5 строк. В конце ответа идёт одна строка о том, что не проверено, и блоки с тем, что осталось сделать. Хук `SessionStart` при старте, `resume`, `clear` и `compact` добавляет в контекст файл [style.md](style.md): около 400 токенов на сессию. Правила написаны по-английски, язык ответа плагин не задаёт: его выбирает ключ `language` в `settings.json`, например `"language": "russian"`. Сабагенты и документы плагин не трогает. Правила про код живут в плагине [vi-code](../vi-code/README.md).

## Установка

До версии 0.2.0 плагин назывался `voice-ru`. Если он стоит под старым именем, сначала удалите его: `/plugin uninstall voice-ru@vizzletf-skills`.

```
/plugin marketplace add VizzleTF/claude-skills
/plugin install vi-voice@vizzletf-skills
```

## Замер

Вопросы взяты из бенчмарка caveman и из кейсов i-have-adhd: 20 вопросов, на которые ответили все три варианта. Модель Opus 5.5, по одному прогону через `claude -p` без инструментов. Правила каждого варианта добавлены через `--append-system-prompt`. Sonnet дважды оценил ответы вслепую по шкале 1–5.

| Вариант | Output | Слов, медиана | Верность | Полнота | Что делать дальше | Правила, слов |
|---|---|---|---|---|---|---|
| черновик 0.4.0 | 20 988 | 187 | 4,45 | 3,92 | 3,77 | 286 |
| caveman 4.0.1 | 27 551 | 268 | 4,45 | 4,53 | 4,38 | 707 |
| i-have-adhd 0.4.1 | 23 120 | 221 | 4,25 | 4,10 | 4,60 | 1187 |

В черновике не было правил о полноте, о допущениях кода и о следующем шаге. С ними на 9 вопросах, где черновик проиграл, полнота выросла с 3,6 до 4,3. Оценка «что делать дальше» тоже выросла с 3,6 до 4,3, а output не изменился. Финальная версия на всех 20 вопросах не перемерялась.

Output включает thinking. Правила читаются на каждом ходу, поэтому их длина влияет на стоимость агентной сессии. В агентном бенчмарке ponytail связка vi-code и vi-voice 0.3.0 стоила на 6% дороже одного vi-code при том же output.

## Удаление

```
/plugin uninstall vi-voice@vizzletf-skills
```
