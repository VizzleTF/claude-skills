# critique

Параллельные субагенты-критики и холодный читатель проверяют вашу работу; Claude перепроверяет каждое замечание и исправляет подтверждённые.

- от 2 до 5 критиков только на чтение, у каждого свой ракурс: корректность, безопасность, документация против поведения и другие
- к каждому замечанию прилагается доказательство: команда и её вывод
- холодный читатель выполняет задачи читателя только по вашей документации и сообщает, где застрял
- правки не выходят за зону, которой вы владеете; замечания вне её приходят списком
- замечания против правил проекта и придирки к стилю отклоняются
- `loop` повторяет раунды по новому диффу, пока не исчезнут критичные и важные замечания, не больше 3
- запускается командой или когда вы просите Claude прогнать критиков или холодного читателя

```
/plugin marketplace add VizzleTF/claude-skills
/plugin install critique@vizzletf-skills
```

Попробуйте `/critique:run charts/app 3 критика по кругу и холодный читатель`.

## Подробнее

- Аргументы на любом языке: цель, число критиков, `loop`, `cold`, `report only`. Без цели проверяется работа текущей сессии.
- Субагенты critic и cold-reader работают на Sonnet. Критику доступны `Read`, `Grep`, `Glob` и `Bash`, холодному читателю только `Read`, а его бриф называет файлы, которые можно читать. Каждый критик стоит одного запуска Sonnet за раунд.
- Ракурсы по видам целей: [lenses.md](skills/run/lenses.md) (на английском).
- Удаление: `/plugin uninstall critique@vizzletf-skills`
