# voice-ru

Плагин задаёт стиль ответов Claude Code в чате: по-русски, вывод первой фразой, без церемоний, код и ошибки дословно. В конце ответа идёт одна строка о том, что не проверено. Хук `SessionStart` при старте, `resume`, `clear` и `compact` добавляет в контекст файл [style.md](style.md): около 300 токенов на сессию. Сабагенты и документы плагин не трогает.

## Установка

```
/plugin marketplace add VizzleTF/claude-skills
/plugin install voice-ru@vizzletf-skills
```

## Замер

12 задач `claude -p`, по 2–3 прогона, без других хуков. Δ дана против прогона без стиля.

| Вариант | Длина ответа | Output без thinking | Стоимость | Точность 1–5 | Попадание в стиль 1–5 | Тесты кода |
|---|---|---|---|---|---|---|
| без стиля | 0% | 0% | 0% | 4,17 | 2,83 | 8/8 |
| voice-ru | −17% | −15% | в шуме | 4,17 | 4,08 | 5/6, с правилом о вызывающих 3/3 |

Точность и стиль оценивал Sonnet вслепую на 6 вопросах. Правило о вызывающих добавлено после того, как без него не исправлялся обходной код у вызывающего; с ним перепроверена только задача с багом.

Стоимость меняется в пределах шума (±10%): ответ модели занимает малую долю счёта. Плагин делает ответы короче и ближе к нужному стилю, а не дешевле.

## Удаление

```
/plugin uninstall voice-ru@vizzletf-skills
```
