# vi-code

Плагин даёт Claude Code и каждому сабагенту один набор правил работы с кодом. С ними Claude:

- читает код до правки и перечисляет вызывающий код, тесты и конфиг, до которых должна дойти правка;
- берёт хелпер из кодовой базы, затем стандартную библиотеку, затем установленную зависимость, а новый код пишет последним;
- не добавляет опций, обёрток и абстракций, о которых не просили, поэтому правка остаётся маленькой;
- сохраняет проверки там, где входят внешние данные (на границах доверия), а ошибки внутри доверенного кода не глушит;
- добавляет один небольшой тест на новую логику;
- находит причину бага и её доказательство до того, как менять код.

В контексте правила занимают около 350 слов: [rules.md](rules.md). Они написаны по-английски и работают с ответом на любом языке.

## Установка

```
/plugin marketplace add VizzleTF/claude-skills
/plugin install vi-code@vizzletf-skills
```

## Как это работает

Хук `SessionStart` при старте, `resume`, `clear` и `compact` добавляет в контекст файл [rules.md](rules.md); хук `SubagentStart` добавляет его каждому сабагенту. Стиль ответов в чате задаёт плагин [vi-voice](../vi-voice/README.ru.md).

## Удаление

```
/plugin uninstall vi-code@vizzletf-skills
```
