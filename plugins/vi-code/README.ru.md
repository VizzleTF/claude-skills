# vi-code

Claude Code делает небольшие правки кода и не забывает места вызова.

- ничего не ломает: до правки перечисляет места вызова, тесты и конфиг
- сначала переиспользует код проекта, затем стандартную библиотеку и установленные зависимости, новый код пишет последним
- не добавляет опций, обёрток и абстракций, о которых не просили
- сохраняет проверки там, где входят внешние данные, а ошибки внутри доверенного кода не глушит
- добавляет один небольшой тест на новую логику
- доказывает причину бага до исправления

```
/plugin marketplace add VizzleTF/claude-skills
/plugin install vi-code@vizzletf-skills
```

## Подробнее

- Правила лежат в [rules.md](rules.md): около 350 слов, по-английски; отвечать Claude может на любом языке.
- Хук `SessionStart` добавляет их при старте, `resume`, `clear` и `compact`; хук `SubagentStart` добавляет их каждому сабагенту.
- Стиль ответов в чате задаёт плагин [vi-voice](../vi-voice/README.ru.md).
- Удаление: `/plugin uninstall vi-code@vizzletf-skills`
