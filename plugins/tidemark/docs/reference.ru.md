# Справочник tidemark

## Содержание

- Команды
- Файлы конфига
- Ключи конфига
- Ключи виджета
- Виджеты
- Опции виджетов
- Пресеты
- Внешние запуски
- Ограничения
- Неполадки

Справочник относится к tidemark 0.1.10. Конфиг читается из двух JSON-файлов, проектный накладывается поверх глобального. Ключ верхнего уровня из проектного файла целиком заменяет такой же ключ глобального: чтобы в проекте добавить один виджет, повторите в проектном файле весь `lines`. Пока файлов нет, действует конфиг по умолчанию; `Save` в редакторе создаёт файл и каталоги к нему. Ручная правка подхватывается на следующем промпте или в течение 30 секунд. Неизвестный ключ, виджет или опция и неверное значение отбрасываются, и редактор показывает предупреждение. Файл, который не разбирается, пропускается: полоса показывает тусклое `⚠ config`, а редактор показывает путь и ошибку.

## Команды

| Команда | Открывает |
|---|---|
| `/tidemark` | Панель деталей. Секция `context`: порог автокомпакции, категории `/context`, пять самых тяжёлых MCP-серверов. Секция `cacheQuota`: hit rate, токены, прогноз исчерпания квоты. Секция `agents`: сессия и 8 последних сабагентов |
| `/tidemark-config` | Редактор: превью, строки, виджеты и их опции, стиль, секции панели, алерты, кнопка компакта, пресеты. Правки идут в черновик. Поле `save to` выбирает файл: `global` или `project`. `Save` пишет черновик в этот файл и применяет, `Revert` отбрасывает |
| `/tidemark-goal [текст]` | С текстом ничего не открывает: задаёт цель, которую показывает виджет `goal`. Без текста открывает поле с текущей целью: Enter задаёт, пустое поле сбрасывает, Esc закрывает. Цель хранится для сессии: `/clear`, перезапуск и `--resume` её сохраняют |
| `/tidemark-project [текст]` | То же для названия проекта, которое показывает виджет `project`. Оно хранится в `.claude/tidemark-project.txt` в каталоге сессии, поэтому его показывает каждая сессия в этом каталоге |

## Файлы конфига

| Файл | Путь |
|---|---|
| Глобальный | `$XDG_CONFIG_HOME/tidemark/config.json`, иначе `~/.config/tidemark/config.json` |
| Проектный | `.claude/tidemark.json` в рабочем каталоге сессии Claude Code |

## Ключи конфига

| Ключ | Тип | По умолчанию | Пределы |
|---|---|---|---|
| `$schema` | строка | `https://raw.githubusercontent.com/VizzleTF/claude-skills/main/plugins/tidemark/config.schema.json` | по этой JSON Schema редактор кода подсказывает ключи и значения; `Save` пишет её сам |
| `version` | число | `1` | только `1`; ключ можно не писать |
| `lines` | массив строк полосы; строка полосы — массив виджетов | одна строка: `context`, `cache`, `quota5h`, `quota7d`, `model`, `git`, `flex`, `compact`, `actions` | 1–3 строки; лишние отбрасываются |
| `style.separator` | строка | `space` | `pipe` (` │ `), `space`, `dot` (` · `), `powerline` (стрелки `▶`, при `icons: "nerd"` глифы Nerd Font), `custom` |
| `style.custom` | строка | нет | разделитель при `separator: "custom"` |
| `style.icons` | строка | `nerd` | `text`, `nerd` (глифы Nerd Font вместо меток и стрелки powerline) |
| `style.buttons` | булево | `true` | `false` рисует нажатия и ссылки из таблицы виджетов обычным текстом |
| `pane.sections` | массив `{id, enabled}` | все три секции включены | `id`: `context`, `cacheQuota`, `agents`; порядок массива задаёт порядок секций |
| `alerts.enabled` | булево | `false` | включает toast при пересечении порога снизу вверх |
| `alerts.context` | число, % израсходованного | `80` | 0–100 |
| `alerts.quota5h` | число, % израсходованного | `90` | 0–100 |
| `alerts.quota7d` | число, % израсходованного | `90` | 0–100 |
| `alerts.cacheSeconds` | число, с | `60` | 0–3600; секунды до остывания кеша |
| `compact.enabled` | булево | `true` | кнопка `/compact` под полосой |
| `compact.at` | целое, % окна контекста | `70` | 1–100 |

Пороги сравниваются с израсходованной долей при любом `mode` виджета. Повторный toast по проценту приходит, когда цифра опустилась на 5 пунктов ниже порога. Toast по кешу приходит один раз на каждую запись кеша. Квотные алерты молчат, пока сессия показывает сохранённую цифру прошлой сессии.

Кнопка `/compact · context 72%` появляется под полосой, когда контекст основного разговора занял `compact.at` процентов окна. Нажатие запускает ту же компакцию, что `/compact`. Пока идёт ход, кнопки нет: движок компактит только между ходами. В терминале кнопку нажимает клавиша `c`, когда фокус на полосе (ctrl+x tab). Порог 70% эвристический: ответы хуже по мере заполнения окна, а автокомпакция ждёт почти полного окна (967k из 1M).

Пример:

```json
{
  "$schema": "https://raw.githubusercontent.com/VizzleTF/claude-skills/main/plugins/tidemark/config.schema.json",
  "version": 1,
  "lines": [
    ["context", "cache", "flex", "quota5h", "quota7d"],
    ["model", { "widget": "cwd", "options": { "style": "short" } }, { "widget": "git", "label": "git", "priority": 45 }]
  ],
  "style": { "separator": "dot", "icons": "text" },
  "alerts": { "enabled": true, "context": 85 },
  "compact": { "at": 75 }
}
```

## Ключи виджета

Виджет в `lines` задаётся именем (`"git"`) или объектом с этими ключами:

| Ключ | Тип | По умолчанию | Пределы |
|---|---|---|---|
| `widget` | строка | обязательный | имя из таблицы «Виджеты» |
| `enabled` | булево | `true` | |
| `label` | строка или `null` | `ctx`, `cache`, `5h`, `7d`, `⏱`, `⇣`; у остальных виджетов метки нет | `null` убирает метку |
| `priority` | целое | приоритет виджета из таблицы «Виджеты» | 0–1000 |
| `options` | объект | опции по умолчанию | ключи из таблицы «Опции виджетов» |

Пока строка шире окна, видимый виджет с наименьшим `priority` (при равенстве правый) теряет очередную деталь, а затем исчезает. Последний оставшийся виджет обрезается с `…`. Виджет, которому нечего показать, скрыт.

## Виджеты

| Виджет | Показывает | Приоритет |
|---|---|---|
| `context` | бар `ctx`, процент, `used/window`, спарклайн роста за 7 последних ходов, последний прирост; `agent`, пока открыт транскрипт сабагента | 100 |
| `quota5h` | `5h 42% ↻ 2h34m` | 80 |
| `cache` | `warm 38m`, `cold`, `rewrote 45k`; `warm` без минут, пока время жизни кеша неизвестно | 70 |
| `quota7d` | `7d 63% ↻ 2d7h`; собственная неделя модели как `7d fable`, если движок её сообщает | 60 |
| `model` | `opus 5.5 · high`; нажатие на название переключает на следующую модель из `cycle`, на effort — на следующий уровень из тех, что перечисляет `/effort` (сейчас `low → medium → high → xhigh → max`), кроме уровней, которые модель понизила. Нажатие выполняет `/model` или `/effort`, как если бы их набрали: перед сменой модели, после которой разговор перечитывается заново, Claude Code спрашивает подтверждение и сохраняет выбор по умолчанию для новых сессий | 50 |
| `git` | ветка или короткий SHA, `*` при незакоммиченных правках, синхронизация с upstream, `+12 −3` относительно HEAD | 40 |
| `cost` | `≈$1.84 (+$0.12)`: сессия и текущий ход | 20 |
| `agents` | спиннер на каждого работающего сабагента, до трёх, дальше `+N` | 20 |
| `cwd` | имя проекта, имя каталога, `~/…/a/b` или полный путь | 20 |
| `sessionTime` | `⏱ 1h12m` с начала разговора | 20 |
| `compactions` | `⇣2` | 20 |
| `tokenSpeed` | `42 t/s` за последний ход | 20 |
| `goal` | `goal <текст>` из `/tidemark-goal`, при нехватке места обрезается до 24 символов; скрыт, пока не задан | 20 |
| `project` | `project <текст>` из `/tidemark-project`, при нехватке места обрезается до 24 символов; скрыт, пока не задан | 20 |
| `command` | первая строка вывода вашей команды, `?` при сбое | 20 |
| `claudeStatus` | `● ok`, `● minor`, `● major`, `● critical` со status.claude.com | 20 |
| `gitPr` | `#123 ✓`, `✗` или `…` для PR или MR текущей ветки; нужен `gh` или `glab` с выполненным входом, без них и без PR виджет скрыт | 20 |
| `compact` | кнопка `/compact`: сжимает разговор, как `/compact`; скрыта на транскрипте сабагента и пока сессия ничего не сообщила | 10 |
| `actions` | маленькая кнопка `⚙`, открывает `/tidemark-config`; скрыта, пока сессия ничего не сообщила | 10 |
| `flex` | ничего; делит строку на группы: один `flex` прижимает виджеты после него к правому краю, два ставят виджеты между ними посередине | не сужается |

Цифры окрашены по шкале из 10 цветов от синего к красному по израсходованной доле.

Часть полосы работает как кнопки и ссылки. Клик работает на десктопе и в полноэкранном терминале; в остальных случаях ctrl+x tab переводит фокус на полосу, Tab переходит между кнопками, Enter нажимает. `style.buttons: false` возвращает их в обычный текст.

| Нажатие на | Что делает |
|---|---|
| метку `context` (`ctx`) | выполняет `/context` |
| метку `quota5h` или `quota7d` | выполняет `/usage` |
| метку `cache` | открывает панель `/tidemark` |
| название модели, effort | следующая модель из `cycle`, следующий уровень effort (см. `model` выше) |
| `/compact` в `compact` | сжимает разговор |
| `⚙` в `actions` | открывает `/tidemark-config` |
| номер в `gitPr` | открывает PR в браузере |
| слово в `claudeStatus` | открывает status.claude.com |

Метка, убранная через `label: null`, кнопкой не бывает.

Синхронизация в `git` сравнивает ветку с её upstream после последнего `git fetch`:

| Отметка | Значит |
|---|---|
| `⇣3` красным | remote впереди на 3 коммита: нужен pull |
| `⇡2` бирюзовым | локальная ветка впереди на 2 коммита: нужен push |
| `⇣3 ⇡2` красным | ветки разошлись |
| `gone` красным | upstream удалён на remote |
| `?` тусклым | последний `git fetch` не удался; цифры по прошлому fetch |

Без upstream и при совпадении с ним отметки нет.

В строке учитываются первые два `flex`, остальные отбрасываются. Группы разносятся по строке с равными промежутками, поэтому средняя группа стоит точно по центру, только когда левая и правая одной ширины. При сужении `flex` остаётся на месте.

## Опции виджетов

У `cost`, `agents`, `sessionTime` и `tokenSpeed` опций нет. TTL задаются в секундах, тайм-ауты в миллисекундах.

| Виджет | Опция | Тип | По умолчанию | Пределы |
|---|---|---|---|---|
| `context` | `mode` | строка | `used` | `used`, `left` (`58% left`; цвет по-прежнему по израсходованной доле) |
| `context` | `barWidth` | целое | `10` | 4–20 |
| `context` | `showTokens` | булево | `true` | |
| `context` | `showGrowth` | булево | `true` | |
| `context` | `showLast` | булево | `true` | |
| `cache` | `showRewrite` | булево | `true` | |
| `cache` | `showMinutes` | булево | `true` | |
| `cache` | `ttl` | строка | `auto` | `auto`, `5m`, `1h` |
| `quota5h`, `quota7d` | `mode` | строка | `used` | `used`, `left` |
| `quota5h`, `quota7d` | `showReset` | булево | `true` | |
| `quota5h`, `quota7d` | `bar` | булево | `false` | |
| `model` | `showEffort` | булево | `true` | |
| `model` | `format` | строка | `short` | `short`, `full` |
| `model` | `cycle` | массив строк | пусто | модели, по которым идёт нажатие на название, в виде, который принимает `/model`. Пусто: модели, которые Claude Code предлагает в `/config`, без `default`, `best` и `opusplan`; пока у текущей модели окно 1M, вместо обычных алиасов берутся `[1m]` |
| `git` | `showDirty` | булево | `true` | |
| `git` | `showDiff` | булево | `true` | |
| `git` | `showSync` | булево | `true` | |
| `git` | `maxLength` | целое | `24` | 4–200 |
| `git` | `ttl` | целое, с | `5` | 1–3600 |
| `git` | `fetch` | целое, с | `300` | 0–86400; `0` выключает `git fetch` |
| `cwd` | `style` | строка | `project` | `project`, `basename`, `short`, `full` |
| `actions` | `config` | булево | `true` | кнопка `⚙` |
| `compactions` | `hideZero` | булево | `true` | |
| `command` | `command` | строка | пусто | запускается как `sh -c <command>` |
| `command` | `maxWidth` | целое | `40` | 4–200 |
| `command` | `timeout` | целое, мс | `2000` | 100–30000 |
| `command` | `ttl` | целое, с | `10` | 1–3600 |
| `claudeStatus` | `ttl` | целое, с | `300` | 30–3600 |
| `gitPr` | `githubHosts` | массив строк | пусто | хосты GitHub в дополнение к `github.com` |
| `gitPr` | `ttl` | целое, с | `120` | 10–3600 |

`cache.ttl: auto` берёт время жизни, которое доказали смена модели, возобновление сессии или пауза дольше пяти минут. До этого берётся первое заданное: `FORCE_PROMPT_CACHING_5M`, `CLAUDE_CODE_PROMPT_CACHE_TTL`, настройка `promptCacheTtl`, `ENABLE_PROMPT_CACHING_1H`. Если ничего не задано, на подписке берётся час, иначе пять минут. Значение `5m` или `1h` фиксирует время жизни и для алерта по кешу.

`command` получает на stdin JSON `{sessionId, model, cwd, contextPercent}`.

## Пресеты

Пресет выбирается в редакторе, меняет черновик и записывается по `Save`.

| Пресет | Строки |
|---|---|
| `minimal` | context, quota5h |
| `classic` | context, cache, quota5h, quota7d |
| `default` | project, context, compact, cache, flex, quota5h, quota7d, flex, sessionTime, git, model, cwd, actions |
| `full` | 1: project, goal, context, cache, quota5h, quota7d, cost; 2: model, cwd, git, sessionTime, compactions, tokenSpeed, agents |
| `powerline` | `default` с `separator: "powerline"` и `icons: "nerd"` |

## Внешние запуски

Выключенный виджет ничего не запускает. Полоса по умолчанию запускает `git` локально и `git fetch` к remote раз в 5 минут.

| Виджет | Запускает | Когда |
|---|---|---|
| `git` | `git status`, `git diff --numstat HEAD` | после каждого хода и на 30-секундном тике, когда прошёл `ttl` |
| `git` с `showSync` | `git fetch --quiet --no-tags` с `GIT_TERMINAL_PROMPT=0`: обновляет ссылки remote, запрос пароля завершается ошибкой | раз в `fetch` секунд |
| `cwd` со `style: "project"` | `git rev-parse --show-toplevel` | не чаще раза в минуту |
| `gitPr` | `git status`, `git remote get-url origin`, затем `gh pr view` для `github.com` и `githubHosts` или `glab mr view` для остальных | когда прошёл `ttl` |
| `command` | `sh -c <command>` | когда прошёл `ttl` |
| `claudeStatus` | HTTPS GET к `status.claude.com` | когда прошёл `ttl` |

Кроме того, tidemark читает свои файлы конфига и пишет файлы двух видов: конфиг по `Save` в `/tidemark-config` и `.claude/tidemark-project.txt` по `/tidemark-project`. В хранилище плагина лежат последняя квота, которую новая сессия показывает тусклой до своей цифры, и цели последних сессий по id сессии. Больше ничего с машины не уходит: в сеть ходят только запуски `git`, `gh`, `glab` и запрос к странице статуса из таблицы выше.

## Ограничения

| Ограничение | Значение |
|---|---|
| Цвета | шкала фиксированная, тем и переопределения цветов нет |
| Ширина | ячейка на кодовую точку; эмодзи и другие широкие глифы недосчитываются |
| Тайм-ауты | `git` 2 с, `git fetch` 15 с, `gh` и `glab` 10 с, страница статуса 5 с; не настраиваются |
| Поверхности | VS Code и mobile полосу не рисуют. Панели открываются на обеих; на mobile `/tidemark-config`, `/tidemark-goal` и `/tidemark-project` без текста показывают заметку вместо полей |

## Неполадки

| Что видно | Что сделать |
|---|---|
| Над промптом нет полосы | Выполните `/reload-plugins`. Проверьте, что `claude --version` не ниже 2.1.288, а `claude plugin list` показывает `tidemark` включённым. VS Code и мобильное приложение полосу не рисуют |
| Тусклое `⚠ config` в конце полосы | Файл конфига не разбирается. `/tidemark-config` показывает путь и ошибку |
| Квадраты или вопросы вместо значков | `icons: "nerd"` без Nerd Font в терминале. Поставьте `style.icons` в `text` |
| `git` ничего не показывает | Каталог сессии не в git-репозитории, или `git` нет в `PATH` |
| Тусклый `?` после синхронизации `git` | `git fetch` не прошёл: нет сети, или удалённый репозиторий просит логин. `git.fetch: 0` отключает fetch |
| Что-то другое | Запустите `claude --debug`: ошибки, после которых мод продолжает работать, tidemark пишет в отладочный лог, строки начинаются с `tidemark` |
