Нужна инструкция по деплою.

Сервис — Moorfen API. Деплой: пушишь тег `vX.Y.Z`, CI собирает образ и сам выкатывает в stage. В prod — после ручного подтверждения, кнопка `promote-prod` в CI. После выкатки проверяем `curl -fsS https://moorfen.example/healthz`, должно вернуть `ok`. Откат — перезапустить `promote-prod` у предыдущего тега. Выкатываем с понедельника по четверг, с 10:00 до 17:00 по Москве.

Что обычно ломается:
- `promote-prod` вне окна падает с `deploy window closed: allowed Mon-Thu 10:00-17:00 MSK` — ждём окна и перезапускаем.
- Тег не по шаблону `vX.Y.Z` (например `v1.2`) пайплайн молча не запускает — удаляем его `git push --delete origin <TAG>` и пушим правильный.
- `healthz` отвечает `degraded: db` вместо `ok` — сервис не видит базу; откатываемся через `promote-prod` предыдущего тега и пишем в #moorfen-dev.
- Сборка падает с `COPY failed: file not found in build context` — в репозитории нет файла, на который ссылается Dockerfile; правим пути и пушим исправление с новым тегом.
