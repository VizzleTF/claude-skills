Напиши README для нашей утилиты tarnlog. Его прочитает разработчик, который впервые открыл репозиторий.

Что это: CLI для чтения и фильтрации JSON-логов, вывод — цветная таблица. Для бэкенд-разработчиков на Linux и macOS, Windows не поддерживаем. Статус — бета, текущая версия 0.9.2.

Установка: `go install example.org/tarnlog/cmd/tarnlog@v0.9.2` (нужен Go 1.22+) или готовый бинарник со страницы релизов.

Пример: `tarnlog -f app.log 'level=error'` показывает только ошибки. С `--since 15m` — только за последние 15 минут.

Синтаксис фильтров подробно описан в `docs/filters.md`. Лицензия MIT.
