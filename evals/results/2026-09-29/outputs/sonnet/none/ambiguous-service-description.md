# Hollin

**Hollin** — сервис уведомлений, отправляющий email, SMS и push-сообщения.

## Владелец
Команда коммуникаций. Основные потребители — продуктовые команды, которые хотят подключиться к сервису для отправки уведомлений своим пользователям.

## API

Отправка уведомления:

```
POST /v1/notifications
```

**Параметры:**

| Поле | Описание |
|---|---|
| `channel` | Канал доставки: email, SMS или push |
| `recipient` | Получатель уведомления |
| `template_id` | Идентификатор шаблона сообщения |
| `params` | Параметры для подстановки в шаблон |

**Rate limit:** 50 запросов в секунду на клиента.

## Шаблоны

Шаблоны сообщений хранятся в отдельном Git-репозитории `hollin-templates`.

## Обработка ошибок доставки

Если доставка не удалась, сервис автоматически повторяет попытку до трёх раз с задержками:

1. через 1 секунду
2. через 4 секунды
3. через 16 секунд

## Инфраструктура

Сервис развёрнут в Kubernetes и работает в четырёх репликах.
