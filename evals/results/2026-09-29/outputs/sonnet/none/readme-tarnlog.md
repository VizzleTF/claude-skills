# tarnlog

CLI-утилита для чтения и фильтрации JSON-логов с выводом в виде цветной таблицы.

Предназначена для бэкенд-разработчиков, работающих в Linux и macOS. Windows не поддерживается.

**Статус: бета** · текущая версия `0.9.2`

## Требования

- Linux или macOS (Windows не поддерживается)
- Go 1.22+ (только для установки через `go install`)

## Установка

Через Go:

```bash
go install example.org/tarnlog/cmd/tarnlog@v0.9.2
```

Либо скачайте готовый бинарник со страницы релизов.

## Использование

Показать только ошибки из файла лога:

```bash
tarnlog -f app.log 'level=error'
```

Показать только события за последние 15 минут:

```bash
tarnlog -f app.log --since 15m 'level=error'
```

Результат выводится в виде цветной таблицы прямо в терминале.
