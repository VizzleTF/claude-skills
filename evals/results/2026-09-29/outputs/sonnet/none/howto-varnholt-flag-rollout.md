# Гайд: включить фича-флаг в Varnholt для части пользователей

## Требования

- Установлен `vhctl` версии 3.
- У вас есть роль `flags-editor`.
- Имя флага: строчные латинские буквы, цифры, дефисы, до 40 символов.

## 1. Создать флаг (если ещё не создан)

```
vhctl flags create <FLAG> --default off
```

Флаг создаётся выключенным по умолчанию.

## 2. Включить на процент пользователей в staging

```
vhctl flags rollout <FLAG> --percent 10 --env staging
```

Пример включает флаг для 10% пользователей. Изменение доезжает до серверов за **до 60 секунд**.

## 3. Проверить, что раскатка применилась

```
vhctl flags get <FLAG> --env staging
```

В выводе должна быть строка:

```
rollout: 10%
```

Если строки нет или процент не совпадает — подождите до 60 секунд и повторите проверку.

## 4. Включить в production

В production та же команда, но обязателен флаг `--confirm`:

```
vhctl flags rollout <FLAG> --percent 10 --env production --confirm
```

Без `--confirm` команда в production не выполнится.

Проверка аналогично:

```
vhctl flags get <FLAG> --env production
```

## 5. Откат

Если нужно откатить раскатку в любом окружении — выставить процент в 0:

```
vhctl flags rollout <FLAG> --percent 0 --env <ENV>
```

Где `<ENV>` — `staging` или `production`. Изменение также применится в течение 60 секунд, проверить командой `get` как в шагах 3–4.
