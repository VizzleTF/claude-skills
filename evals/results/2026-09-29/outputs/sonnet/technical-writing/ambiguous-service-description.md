# Hollin

Hollin — сервис уведомлений: отправляет email, SMS и push по одному запросу к API.

Документ для разработчиков продуктовых команд, которые хотят подключиться к Hollin.

## Как подключиться

1. Найдите шаблон в репозитории `hollin-templates` или добавьте свой: `<ПРОЦЕСС_ДОБАВЛЕНИЯ_ШАБЛОНА>`.
2. Получите доступ к API: `<КАК_ПОЛУЧИТЬ_КЛЮЧ_ИЛИ_ТОКЕН>`.
3. Отправьте запрос `POST /v1/notifications`.

## Пример запроса

```bash
curl -X POST <HOLLIN_URL>/v1/notifications \
  -H "<ЗАГОЛОВОК_АВТОРИЗАЦИИ>" \
  -H "Content-Type: application/json" \
  -d '{
    "channel": "email",
    "recipient": "<АДРЕС_ПОЛУЧАТЕЛЯ>",
    "template_id": "<ID_ШАБЛОНА>",
    "params": {"<ИМЯ_ПАРАМЕТРА>": "<ЗНАЧЕНИЕ>"}
  }'
```

Ответ: `<ПРИМЕР_УСПЕШНОГО_ОТВЕТА>`.

| Поле | Значение |
|---|---|
| `channel` | Канал доставки: `email`, `sms` или `push` |
| `recipient` | Получатель |
| `template_id` | Идентификатор шаблона из `hollin-templates` |
| `params` | Значения для подстановки в шаблон |

## Ограничения и поведение

- Лимит: 50 запросов в секунду на клиента. Ответ при превышении: `<КОД_И_ТЕЛО_ОТВЕТА_ПРИ_ПРЕВЫШЕНИИ>`.
- Если доставка не удалась, Hollin повторяет отправку три раза: через 1, 4 и 16 секунд.
- Hollin работает в Kubernetes, четыре реплики.
