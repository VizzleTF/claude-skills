# tarnlog

CLI для чтения и фильтрации JSON-логов: выводит записи в виде цветной таблицы. Предназначена для бэкенд-разработчиков на Linux и macOS, Windows не поддерживается.

Статус: бета, текущая версия 0.9.2.

## Установка

Нужен Go 1.22 или новее:

```sh
go install example.org/tarnlog/cmd/tarnlog@v0.9.2
```

Или скачайте готовый бинарник со [страницы релизов](<RELEASES_URL>).

## Пример

Показать только ошибки из `app.log`:

```sh
tarnlog -f app.log 'level=error'
```

Вывод:

```
<OUTPUT>
```

Чтобы оставить только записи за последние 15 минут, добавьте `--since`:

```sh
tarnlog -f app.log --since 15m 'level=error'
```
