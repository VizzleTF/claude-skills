# tarnlog

CLI для чтения и фильтрации JSON-логов. Результат выводится цветной таблицей.

Рассчитан на бэкенд-разработчиков на Linux и macOS. Windows не поддерживается.

**Статус:** бета, текущая версия 0.9.2.

## Установка

Нужен Go 1.22 или новее:

```sh
go install example.org/tarnlog/cmd/tarnlog@v0.9.2
```

Либо скачайте готовый бинарник со страницы релизов репозитория.

## Использование

Показать только ошибки:

```sh
tarnlog -f app.log 'level=error'
```

Только ошибки за последние 15 минут:

```sh
tarnlog -f app.log --since 15m 'level=error'
```

Полный синтаксис фильтров описан в [docs/filters.md](docs/filters.md).
