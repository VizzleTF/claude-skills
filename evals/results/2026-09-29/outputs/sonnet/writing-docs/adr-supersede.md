```markdown
# ADR-0015: Хранить пользовательские сессии в PostgreSQL

- Статус: принято
- Дата: 2026-09-28
- Заменяет: [ADR-0007](ADR-0007-sessions-in-redis.md)

## Контекст

Сессии хранятся в кластере Redis 7 (ADR-0007). Чтобы сократить расходы, кластер Redis выводится из эксплуатации до 2026-12-01.

В 2025 году таблицу сессий в PostgreSQL отклонили из-за нагрузки на запись. В 2026 году аналитику вынесли в отдельное хранилище, и нагрузка на запись снизилась.

## Решение

Мы храним сессии в таблице `sessions` существующего кластера PostgreSQL 16. Отдельный кластер Redis больше не нужен.

- Время жизни сессии — 14 дней, продлевается при каждом запросе, как и раньше.
- Устаревшие сессии удаляет задача `pg_cron` раз в 10 минут.
- Кластер Redis выводится из эксплуатации до 2026-12-01.

## Последствия

- Чтение сессии занимает 3,1 мс на p99 против 0,8 мс в Redis. Бюджет — 20 мс, запас достаточный.
- Команда платформы перестаёт сопровождать кластер Redis, расходы на него исчезают.
- Доступность сессий равна доступности PostgreSQL.
- Продление при каждом запросе — это запись в PostgreSQL на каждый запрос. Нагрузка на запись растёт вместе с трафиком.

## Альтернативы

Redis оставить: отклонено из-за расходов на отдельный кластер.
```

**`docs/adr/ADR-0007-sessions-in-redis.md`** (изменена только строка статуса)

```markdown
# ADR-0007: Хранить пользовательские сессии в Redis

- Статус: заменено [ADR-0015](ADR-0015-sessions-in-postgresql.md) (2026-09-28)
- Дата: 2025-03-12

## Контекст

Сервис Varnholt хранит сессии пользователей в памяти каждого экземпляра API. При перезапуске экземпляра пользователи теряют сессию и входят заново. С переходом на несколько экземпляров за балансировщиком сессия должна быть доступна любому экземпляру.

## Решение

Мы храним сессии в отдельном кластере Redis 7 из трёх узлов. Ключ сессии — `session:<id>`, время жизни — 14 дней, продлевается при каждом запросе.

## Последствия

Сессии переживают перезапуск и перенос экземпляров. Чтение сессии занимает около 0,8 мс на p99. Команда платформы сопровождает ещё один кластер Redis. Если кластер Redis недоступен, пользователи не могут войти.

## Альтернативы

Липкие сессии на балансировщике отклонены: при отказе экземпляра сессия всё равно теряется. Таблица в PostgreSQL отклонена: в 2025 году основной кластер PostgreSQL работал на пределе по записи.
```
