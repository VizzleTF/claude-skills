# Hollin

Hollin — сервис уведомлений. Принимает запрос по HTTP и отправляет email, SMS или push. Владелец — команда коммуникаций.

Страница для продуктовых команд, которые хотят подключиться и отправлять уведомления без собственной доставки.

## Как подключиться

1. Убедитесь, что нужный шаблон есть в Git-репозитории `hollin-templates`. Его идентификатор понадобится в поле `template_id`.
2. Отправьте `POST /v1/notifications` с полями из таблицы ниже.

## API

`POST /v1/notifications`

| Поле | Что передать |
|---|---|
| `channel` | Канал доставки: email, SMS или push |
| `recipient` | Получатель: адрес, номер или токен устройства, в зависимости от канала |
| `template_id` | Идентификатор шаблона из `hollin-templates` |
| `params` | Значения, которые подставляются в шаблон |

## Лимиты и повторы

| Что | Как работает |
|---|---|
| Лимит запросов | 50 запросов в секунду на клиента |
| Повторы при неудачной доставке | Три попытки: через 1, 4 и 16 секунд |

## Шаблоны

Шаблоны хранятся в Git-репозитории `hollin-templates`. Сервис берёт шаблон по `template_id` и подставляет `params`.

## Эксплуатация

- Работает в Kubernetes, четыре реплики.
- Владелец: команда коммуникаций.
