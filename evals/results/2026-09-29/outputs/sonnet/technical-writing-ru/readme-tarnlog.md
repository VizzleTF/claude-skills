# tarnlog

Утилита командной строки, которая читает JSON-логи, фильтрует записи и выводит их цветной таблицей. Для бэкенд-разработчиков на Linux и macOS. Windows не поддерживается.

Статус: бета, версия 0.9.2.

## Установка

Установите через Go 1.22 или новее:

```sh
go install example.org/tarnlog/cmd/tarnlog@v0.9.2
```

Либо скачайте готовый бинарник со [страницы релизов](<RELEASES_URL>).

## Пример

Покажите из `app.log` только ошибки:

```sh
tarnlog -f app.log 'level=error'
```

Добавьте `--since 15m`, чтобы оставить ошибки за последние 15 минут:

```sh
tarnlog -f app.log --since 15m 'level=error'
```
