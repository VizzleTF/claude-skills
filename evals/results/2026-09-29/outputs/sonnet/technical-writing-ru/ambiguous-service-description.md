# Hollin

Hollin — сервис уведомлений: отправляет email, SMS и push по запросам от других сервисов.

Он для продуктовых команд, которые хотят слать уведомления пользователям.

## Как подключиться

1. Выберите шаблон в Git-репозитории `hollin-templates` или добавьте туда новый. Hollin берёт шаблоны оттуда.
2. Отправьте запрос:

```bash
curl -X POST https://<HOLLIN_HOST>/v1/notifications \
  -H "Content-Type: application/json" \
  -d '{
    "channel": "email",
    "recipient": "<RECIPIENT>",
    "template_id": "<TEMPLATE_ID>",
    "params": {"<PARAM_NAME>": "<PARAM_VALUE>"}
  }'
```

Успешный ответ: `<RESPONSE_EXAMPLE>`.

| Поле | Значение |
|---|---|
| `channel` | Канал доставки: `email`, `sms` или `push`. |
| `recipient` | Получатель. Формат: `<RECIPIENT_FORMAT>`. |
| `template_id` | Идентификатор шаблона из `hollin-templates`. |
| `params` | Значения, которые подставляются в шаблон. |

## Лимиты и повторы

- Лимит — 50 запросов в секунду на клиента.
- Если доставка не удалась, Hollin повторяет отправку три раза: через 1, 4 и 16 секунд.
