# Выкатить Moorfen API

Инструкция для инженера, который выкатывает релиз Moorfen API в stage и prod.

**Предпосылки:** права на push тегов в репозиторий и доступ к кнопке `promote-prod` в CI. В prod выкатываем с понедельника по четверг, с 10:00 до 17:00 по Москве.

1. Создайте тег по шаблону `vX.Y.Z`, например `v1.2.3`:

   ```bash
   git tag <TAG>
   ```

2. Запушьте тег:

   ```bash
   git push origin <TAG>
   ```

   CI сам соберёт образ и выкатит его в stage.

3. Если сейчас вне окна выкатки, дождитесь его. Затем нажмите `promote-prod` в CI и подтвердите выкатку в prod.
4. Проверьте prod:

   ```bash
   curl -fsS https://moorfen.example/healthz
   ```

   Успешная выкатка отвечает `ok`.

## Если не сработало

Чтобы откатить релиз, перезапустите `promote-prod` у предыдущего тега.

- **`promote-prod` падает с `deploy window closed: allowed Mon-Thu 10:00-17:00 MSK`.** Вы вне окна выкатки. Дождитесь окна и перезапустите `promote-prod`.
- **После пуша тега пайплайн не запустился.** Тег не подходит под шаблон `vX.Y.Z` (например, `v1.2`), и CI молча его пропускает. Удалите тег командой `git push --delete origin <TAG>` и запушьте правильный.
- **`healthz` отвечает `degraded: db`.** Сервис не видит базу. Откатитесь на предыдущий тег и напишите в #moorfen-dev.
- **Сборка падает с `COPY failed: file not found in build context`.** В репозитории нет файла, на который ссылается Dockerfile. Исправьте пути в Dockerfile и запушьте исправление с новым тегом.
