# Как включить фича-флаг для части пользователей

Эта инструкция объясняет, как через `vhctl` включить флаг в Varnholt для части пользователей, проверить результат и откатить его. Она написана для `vhctl` версии 3.

## Что нужно заранее

- `vhctl` версии 3.
- Роль `flags-editor`.

В командах ниже `<FLAG>` — это имя флага. Оно может содержать строчные латинские буквы, цифры и дефисы, длина до 40 символов. Пример: `new-checkout-v2`.

## Включение в staging

1. Создайте флаг. Если флаг уже существует, пропустите этот шаг.

   ```sh
   vhctl flags create <FLAG> --default off   # флаг создаётся выключенным для всех
   ```

2. Включите флаг для 10% пользователей:

   ```sh
   vhctl flags rollout <FLAG> --percent 10 --env staging
   ```

3. Подождите 60 секунд, пока изменение применится, и проверьте флаг:

   ```sh
   vhctl flags get <FLAG> --env staging
   ```

   Если всё прошло успешно, в выводе будет строка:

   ```
   rollout: 10%
   ```

## Включение в production

Используйте ту же команду с `--env production`. В production обязателен флаг `--confirm`:

```sh
vhctl flags rollout <FLAG> --percent 10 --env production --confirm
```

Через 60 секунд проверьте флаг командой `vhctl flags get <FLAG> --env production`.

## Откат

Задайте 0%. Изменение применится в течение 60 секунд.

```sh
vhctl flags rollout <FLAG> --percent 0 --env staging
vhctl flags rollout <FLAG> --percent 0 --env production --confirm
```

После отката команда `get` должна показать `rollout: 0%`.
