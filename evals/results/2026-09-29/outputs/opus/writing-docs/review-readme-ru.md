# Ревью `README.md` (Brinebak)

Главная проблема: человек, который впервые открыл репозиторий, не может ни установить утилиту, ни запустить её. Команда установки ставит другой пакет. Команды запуска в README нет. Настройка отправляет в «документацию», на которую нет ссылки. Первый экран занят историей проекта и рекламой вместо описания того, что делает утилита.

Файл я не менял, это только ревью. Кроме `README.md`, в каталоге ничего нет, поэтому формат `brinebak.yaml`, настройку расписания, шифрование и проверку восстановления сверить было не с чем. Эти места в предложенной версии отмечены как `TODO`.
