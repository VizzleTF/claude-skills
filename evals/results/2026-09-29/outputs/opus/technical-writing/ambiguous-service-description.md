# Hollin

Hollin — сервис уведомлений команды коммуникаций. Он отправляет email, SMS и push через один HTTP-метод `POST /v1/notifications`. Эта страница для продуктовых команд, которые хотят подключиться к Hollin.

## Подключение

1. Получите доступ: <КАК_ПОЛУЧИТЬ_ДОСТУП>.
2. Найдите или добавьте шаблон уведомления в Git-репозитории [`hollin-templates`](<HOLLIN_TEMPLATES_URL>). Идентификатор шаблона передаётся в поле `template_id`.
3. Отправьте запрос:

```bash
curl -X POST "<HOLLIN_URL>/v1/notifications" \
  -H "Content-Type: application/json" \
  -H "<AUTH_HEADER>" \
  -d '{
    "channel": "email",
    "recipient": "<RECIPIENT>",
    "template_id": "<TEMPLATE_ID>",
    "params": {"<PARAM>": "<VALUE>"}
  }'
```

Ответ при успехе: `<RESPONSE_EXAMPLE>`.

| Поле | Значение |
|---|---|
| `channel` | Канал доставки: `email`, `sms` или `push` |
| `recipient` | Получатель. Формат зависит от канала: <RECIPIENT_FORMAT> |
| `template_id` | Идентификатор шаблона из `hollin-templates` |
| `params` | Значения для подстановки в шаблон |

## Ограничения

- Не больше 50 запросов в секунду на клиента.
- Если доставка не удалась, Hollin повторяет её три раза: через 1, 4 и 16 секунд.
