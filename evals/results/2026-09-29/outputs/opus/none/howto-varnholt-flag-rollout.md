# Как включить фича-флаг для части пользователей

Гайд описывает, как создать флаг в Varnholt, включить его для процента пользователей, проверить результат и при необходимости откатить изменение.

## Перед началом

- Установлен `vhctl` версии 3.
- У вас есть роль `flags-editor`.
- Имя флага состоит только из строчных латинских букв, цифр и дефисов, длина до 40 символов. Пример: `new-checkout-v2`.

В примерах ниже вместо `<FLAG>` подставьте имя своего флага.

## 1. Создайте флаг

Если флаг уже существует, переходите к шагу 2.

```sh
vhctl flags create <FLAG> --default off
```

Флаг создаётся выключенным: пока вы не зададите раскатку, никто из пользователей его не получит.

## 2. Включите флаг в staging

Пример включает флаг для 10% пользователей:

```sh
vhctl flags rollout <FLAG> --percent 10 --env staging
```

## 3. Проверьте результат

Изменение применяется в течение 60 секунд. Подождите минуту и выполните:

```sh
vhctl flags get <FLAG> --env staging
```

В выводе должна быть строка:

```
rollout: 10%
```

## 4. Включите флаг в production

Для production используется та же команда, но с обязательным флагом `--confirm`:

```sh
vhctl flags rollout <FLAG> --percent 10 --env production --confirm
```

Через 60 секунд проверьте результат так же, как в шаге 3, указав `--env production`.

## Откат

Чтобы выключить флаг для всех пользователей окружения, установите раскатку на 0%:

```sh
vhctl flags rollout <FLAG> --percent 0 --env <ENV>
```

Вместо `<ENV>` укажите `staging` или `production`. Для production, как и при включении, добавьте `--confirm`. Откат тоже применяется в течение 60 секунд.
