# Включить фича-флаг в Varnholt для части пользователей

Используйте эти шаги, чтобы запустить флаг на выбранном проценте пользователей в staging перед тем, как выкатить в production.

## Предпосылки

Роль `flags-editor` и `vhctl` версии 3.

## Шаги

1. Выберите имя флага: строчные буквы, цифры и дефисы, до 40 символов. Например, `new-search-ui`.

2. Создайте флаг:
   ```
   vhctl flags create new-search-ui --default off
   ```

3. Включите флаг на нужный процент в staging:
   ```
   vhctl flags rollout new-search-ui --percent 10 --env staging
   ```

4. Подождите 60 секунд, пока изменение распространится.

5. Проверьте результат:
   ```
   vhctl flags get new-search-ui --env staging
   ```
   Команда должна вывести строку `rollout: 10%`.

6. Когда флаг будет готов, включите его в production. Используйте ту же команду с флагом `--confirm`:
   ```
   vhctl flags rollout new-search-ui --percent 10 --env production --confirm
   ```

## Откат

Если флаг нужно отключить:
```
vhctl flags rollout new-search-ui --percent 0 --env <ENV>
```
Замените `<ENV>` на `staging` или `production`.
