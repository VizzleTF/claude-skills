## Итоговый документ

# Hollin

Сервис отправляет письма, SMS и push-уведомления через единый API.

## API

### POST /v1/notifications

| Параметр | Тип | Обязательный | Пределы | Пример |
|---|---|---|---|---|
| `channel` | строка | да | `email`, `sms`, `push` | `"email"` |
| `recipient` | строка | да | адрес, номер или ID | `"user@example.com"` |
| `template_id` | строка | да | идентификатор в hollin-templates | `"welcome-email"` |
| `params` | объект JSON | нет | любые ключи и значения | `{"name": "John"}` |

## Лимиты

Rate limit — 50 запросов в секунду на клиента.

## Доставка при ошибке

Повторяет попытку доставки три раза с интервалами в 1, 4 и 16 секунд.

## Шаблоны

Хранятся в Git-репозитории `hollin-templates`.
