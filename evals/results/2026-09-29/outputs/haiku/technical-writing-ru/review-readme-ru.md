Требуемый каркас README (из types/readme.md):
1. Название и одно предложение: что это за проект и какую проблему решает
2. Для кого он (если не видно)
3. Установка с версиями
4. Минимальный пример с выводом
5. Ссылки на документацию, лицензию, поддержку

## Список проблем

1. **Раздел «Название и введение» (строки 1–5)**: вводный текст содержит happy talk («философия», «бесшемно встраивается», «самое ценное»), который запрещён в README. Первое предложение должно конкретно назвать, что это и какую проблему решает. **Исправить**: заменить вводный текст на одно предложение типа «Brinebak делает резервные копии PostgreSQL по расписанию в S3-совместимое хранилище».

2. **Раздел «Установка», строка 17**: команда `pip install brinebak` неверна — пакет на PyPI называется `brinebak-cli`. Также не указаны требуемые версии Python. **Исправить**: написать `pip install brinebak-cli` и добавить строку о требовании Python 3.10+.

3. **Раздел «Возможности» (строки 7–12)**: этот раздел не входит в каркас README. Список фичей повторяет информацию из первого предложения, занимает место, которое нужно минимальному примеру. **Исправить**: удалить раздел или переместить в документацию.

4. **Раздел «Настройка», строка 22**: описание слишком поверхностно, отсылает на документацию (которую читатель ещё не открывал). README должен быть самодостаточен до ссылок. **Исправить**: добавить минимальный рабочий пример с файлом конфигурации и выводом: `brinebak run --config brinebak.yaml`.

5. **Отсутствует минимальный пример (пункт 4 каркаса)**: нет команды с видимым результатом. Читатель не может проверить, что инструмент установился и работает. **Исправить**: добавить раздел «Минимальный пример» с командой и её выводом.

6. **Отсутствуют ссылки (пункт 5 каркаса)**: нет ссылок на документацию, участие в разработке, лицензию. Раздел «Вопросы» предлагает только issues, это не полный набор ссылок. **Исправить**: добавить раздел со ссылками на: документацию, changelog, лицензию, способы помощи.

7. **Рекламный язык (строки 3–5)**: фразы «целая философия надёжного хранения данных», «бесшемно встраивается», «самое ценное» — это маркетинговый стиль, запрещённый в README. **Исправить**: удалить или заменить на факты.
