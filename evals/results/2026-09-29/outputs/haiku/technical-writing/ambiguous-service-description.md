# Hollin — сервис уведомлений

Hollin отправляет email, SMS и push-уведомления. API: `POST /v1/notifications`.

## Параметры API

| Параметр | Тип | Требуется | Описание |
|---|---|---|---|
| `channel` | строка | Да | `email`, `sms` или `push` |
| `recipient` | строка | Да | Email, номер телефона или ID пользователя |
| `template_id` | строка | Да | ID шаблона из репозитория `hollin-templates` |
| `params` | объект | Нет | Переменные для подстановки в шаблон |

**Пример**:
```json
POST /v1/notifications
{
  "channel": "email",
  "recipient": "user@example.com",
  "template_id": "welcome",
  "params": {"name": "Alice"}
}
```

## Ограничения

50 запросов в секунду на клиента.

## Повторы при сбое

При неудаче доставка повторяется три раза со следующими интервалами: через 1 сек, 4 сек, 16 сек. После третьей неудачной попытки запрос отмечается как неудачный.

Kubernetes, 4 реплики.
