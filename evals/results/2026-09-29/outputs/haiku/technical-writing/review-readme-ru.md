## Исправленный README

```markdown
# Brinebak

Утилита для автоматизированного резервного копирования PostgreSQL в S3-совместимое хранилище по расписанию.

## Установка

Требуется Python 3.10+.

```bash
pip install brinebak-cli
```

## Быстрый старт

Создайте файл конфигурации `brinebak.yaml`:

```yaml
postgres:
  host: localhost
  port: 5432
  user: postgres
  password: <PASSWORD>
  database: mydb

s3:
  endpoint: https://s3.amazonaws.com
  bucket: my-backups
  access_key: <KEY>
  secret_key: <SECRET>

schedule:
  cron: "0 2 * * *"  # каждый день в 2:00
```

Затем запустите:

```bash
brinebak run --config brinebak.yaml
```

При успехе увидите:

```
✓ Backup started: mydb_2026-09-29_020000
✓ Uploaded to S3: s3://my-backups/mydb_2026-09-29_020000.sql.gz
```
