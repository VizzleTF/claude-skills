## Исправленный README.md

```markdown
# Brinebak

Всё началось в 2023 году, когда наша команда устала от ручных бэкапов. Мы долго искали подходящий инструмент, пробовали разные варианты и в итоге решили написать свой. Так появился Brinebak.

Brinebak — это не просто инструмент, а целая философия надёжного хранения данных. В современном мире данные — это самое ценное, что есть у компании, и Brinebak бесшумно встраивается в вашу инфраструктуру.

## Возможности

- Снапшоты PostgreSQL по расписанию
- Хранение бэкапов в S3-совместимом хранилище
- Шифрование снапшотов
- Проверка восстановления

## Требования

- Python 3.10 или выше

## Установка

```
pip install brinebak-cli
```

## Быстрый старт

Создайте файл конфигурации `brinebak.yaml`:

```yaml
postgres:
  host: localhost
  port: 5432
  database: mydb

s3:
  endpoint: https://s3.example.com
  bucket: my-backups
  access_key: YOUR_KEY
  secret_key: YOUR_SECRET

schedule: "0 2 * * *"  # Ежедневно в 2:00 AM
```

Запустите утилиту:

```bash
brinebak run --config brinebak.yaml
```
