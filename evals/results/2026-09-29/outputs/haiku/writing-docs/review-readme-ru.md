## Исправленный README.md

```markdown
# Brinebak

Автоматизированное резервное копирование PostgreSQL с сохранением в S3-совместимое хранилище.

Brinebak запускает резервные копии по расписанию, управляет ротацией и проверяет восстановимость ваших данных. Поддерживает шифрование и работает с любым S3-совместимым хранилищем.

## Требования

- Python 3.10+
- PostgreSQL 10+
- Доступ к S3-совместимому хранилищу (AWS S3, MinIO, Yandex S3 и др.)

## Установка

```sh
pip install brinebak-cli
```

## Быстрый старт

1. Создайте файл конфигурации `brinebak.yaml`:

```yaml
database:
  host: localhost
  port: 5432
  name: mydb
  user: postgres
  password: secret

storage:
  type: s3
  endpoint: s3.amazonaws.com
  bucket: my-backups
  access_key: YOUR_KEY
  secret_key: YOUR_SECRET

schedule: "0 2 * * *"  # каждый день в 2:00 UTC
retention_days: 30
```

2. Запустите резервное копирование:

```sh
brinebak run --config brinebak.yaml
```

Инструмент создаст бэкап, загрузит его в S3 и проверит восстановимость.

## Возможности

| Возможность | Описание |
|---|---|
| Снапшоты по расписанию | Запуск по расписанию cron без ручного вмешательства |
| S3-совместимое хранилище | Работает с AWS S3, MinIO, DigitalOcean Spaces, Yandex S3 |
| Шифрование | Автоматическое шифрование перед загрузкой в облако |
| Проверка восстановления | Валидация каждого бэкапа перед удалением старых |
| Ротация | Автоматическое удаление старых резервных копий |

## Рекомендуемая настройка

Для использования в production:

- Установите как системный сервис (systemd, cron)
- Используйте переменные окружения вместо паролей в конфиге
- Включите шифрование в конфигурации
- Настройте мониторинг и оповещения о сбоях
