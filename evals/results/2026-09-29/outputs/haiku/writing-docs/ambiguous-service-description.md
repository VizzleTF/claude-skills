# Hollin — сервис уведомлений

Hollin отправляет пользователям сообщения по email, SMS и push. Используйте его для подтверждений, напоминаний и уведомлений о событиях.

## API

```
POST /v1/notifications
```

| Поле | Значение | Описание |
|---|---|---|
| `channel` | `email`, `sms`, `push` | Канал доставки |
| `recipient` | строка | Email, номер или ID пользователя |
| `template_id` | строка | ID из репозитория `hollin-templates` |
| `params` | объект | Переменные для подстановки в шаблон |

**Лимит:** 50 запросов в секунду на клиента.

## Надёжность

Если доставка не удалась, Hollin повторяет отправку:
- через 1 секунду
- через 4 секунды
- через 16 секунд

Если и третий раз не сработал — сообщение не доставляется.

## Шаблоны

Шаблоны хранятся в репозитории `hollin-templates`. Создайте шаблон один раз, потом используйте его `template_id` в API.

## Контакты

Владелец сервиса — команда коммуникаций. Вопросы по подключению или использованию — обратитесь к ним.
