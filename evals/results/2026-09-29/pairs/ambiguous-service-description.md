# Hollin

Hollin — сервис уведомлений: отправляет email, SMS и push по запросам от других сервисов.

Он для продуктовых команд, которые хотят слать уведомления пользователям.

## Как подключиться

1. Выберите шаблон в Git-репозитории `hollin-templates` или добавьте туда новый. Hollin берёт шаблоны оттуда.
2. Отправьте запрос:

```bash
curl -X POST https://<HOLLIN_HOST>/v1/notifications \
  -H "Content-Type: application/json" \
  -d '{
    "channel": "email",
    "recipient": "<RECIPIENT>",
    "template_id": "<TEMPLATE_ID>",
    "params": {"<PARAM_NAME>": "<PARAM_VALUE>"}
  }'
```
