# Brinebak

Всё началось в 2023 году, когда наша команда устала от ручных бэкапов. Мы долго искали подходящий инструмент, пробовали разные варианты и в итоге решили написать свой. Так появился Brinebak.

Brinebak — это не просто инструмент, а целая философия надёжного хранения данных. В современном мире данные — это самое ценное, что есть у компании, и Brinebak бесшовно встраивается в вашу инфраструктуру.

## Возможности

- Снапшоты PostgreSQL по расписанию
- Хранение бэкапов в S3-совместимом хранилище
- Шифрование снапшотов
- Проверка восстановления

## Установка

```
pip install brinebak
```

## Настройка

Создайте файл конфигурации и укажите в нём параметры подключения. Подробности смотрите в документации.
