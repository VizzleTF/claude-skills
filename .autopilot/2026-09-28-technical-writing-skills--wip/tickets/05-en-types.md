## Что должно заработать

Английская версия получает 13 файлов в `types/`. Имена берутся из спецификации §2. В каждом файле семь разделов по порядку, каркас и голос из брифа, исключения из общих правил на своём месте. Файлы не ссылаются на другие файлы скилла.

## Из брифа, дословно

> «Файл на каждый тип. Одинаковые разделы во всех: «Когда это он и когда нет», «Каркас», «Голос и глаголы», «Объём», «Отличия от общих правил», «Запрещено», «Чек-лист типа».»
> «Ссылки только на один уровень от `SKILL.md`: файл типа не отправляет к файлу стиля»
> «Эти исключения скилл должен знать явно. В `writing-docs` их нет, из-за этого он даёт неверные советы для части типов.»
> «Diátaxis применён слишком жёстко: «ноль объяснений» в tutorial.»

## Разделы спецификации

Истории 11–17; Решения §2 (разделы, голос для README/troubleshooting/`--help`), §2a (источники по типам); бриф — таблицы «Классификация», «Правила по типам», «Где общие правила ломаются». Прочитай готовый `SKILL.md` из таска 02: глоссарий и термины оттуда обязательны.

## Критерии приёмки

- [ ] 13 файлов: `tutorial.md how-to.md runbook.md troubleshooting.md reference.md explanation.md readme.md conventions.md adr.md postmortem.md changelog.md docstring.md cli-help-errors.md`
- [ ] Разделы, заголовки второго уровня в этом порядке: `When to use it and when not`, `Skeleton`, `Voice and verbs`, `Length`, `Differences from the core rules`, `Forbidden`, `Type checklist`; чек-лист — пункты `- [ ]`
- [ ] Каркас каждого типа совпадает с таблицами брифа; голос и глаголы — с таблицей «Правила по типам»; README, troubleshooting, `--help` — по §2
- [ ] Пять исключений брифа («удалить неправдивое», «список из >2», «второе лицо», «ответ первым», «ни одного дубля») записаны у своих типов в `Differences from the core rules`
