**Требования:** R09, R09.1, R10, R42, R43, R44, R45, R46, R48, R48.1, R63, R65 (метки core), R60
**Blocked by:** —

**Волна:** 1
**Status:** ready

## Что должно заработать

В `evals/` лежат 27–30 сценариев в формате §6. Минимум один сценарий на каждый из 13 типов, три неоднозначных запроса, два ревью, `adr-supersede`, 8–10 сценариев на реальных документах из публичных репозиториев. Около 8 сценариев помечены `core`. Рядом лежат фикстуры с источником и лицензией и рубрика судьи с якорями.

## Из брифа, дословно

> «Минимум один на каждый тип из классификации, плюс: неоднозначные запросы: «напиши описание сервиса», «сделай методичку для новых девопсов», «нужна инструкция по деплою»; ревью существующего текста; правка записи: «обнови ADR-0007, решение поменялось» — ожидается новая запись со `supersedes`; сценарии на русском и на английском.»
> «Реальные документы — только из публичных репозиториев»
> «Рубрика: верно выбран тип; каркас типа соблюдён; фактическая точность; ответ первым; сканируемость; голос и глаголы по типу; отсутствие LLM-паттернов; объём без воды; пригодность к действию.»
> Дополнение: «Подберу сам» — агент подбирает 8–10 OSS-документов с открытой лицензией.

Истории 46–52, 55–57; Решения §6, §7.

## Критерии приёмки

- [ ] Формат каждого файла строго по §6 (заголовок `ключ: значение`, `facts:` списком, пустая строка, текст запроса); `id` равен имени файла
- [ ] Покрытие: все 13 значений `expect` из §2 встречаются ≥ 1 раза как единственный ожидаемый тип; 3 неоднозначных сценария с текстами из брифа (RU) и списком допустимых типов; ≥ 2 ревью (EN, RU); `adr-supersede` с фикстурой ADR-0007 и фактом «ожидается новая запись со `supersedes`, старая не переписывается, помечается superseded»
- [ ] Каждый язык — не меньше трети сценариев
- [ ] 8–10 реальных документов: только из публичных репозиториев, лицензия Apache-2.0, MIT, BSD или CC BY; `evals/fixtures/SOURCES.md` — URL, коммит (SHA), лицензия, что изменено (обрезка); документы разных типов
- [ ] Синтетические сценарии: вымышленный продукт и полный набор фактов, чтобы документ можно было написать без выдумки; факты проверяемы судьёй
- [ ] ~8 сценариев `core: true`: разные типы, оба языка, все `kind`
- [ ] `evals/rubric.md`: 9 критериев, у каждого якоря 1/3/5; правила «длина не заслуга», «верное уточнение неоднозначного запроса засчитывается», «стиль — по языку документа»; критерии применимы к `kind: review` (отчёт ревью — тоже документ)
- [ ] Нет приватных данных, внутренних хостов, реальных людей кроме авторов в `SOURCES.md`
